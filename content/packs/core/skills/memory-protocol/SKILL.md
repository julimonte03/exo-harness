# memory-protocol

> Esqueleto de F2. La memoria persistente llega en F3 con los comandos `exo mem …`.

## Cuándo usar la memoria

- **Al empezar:** buscá contexto del proyecto antes de investigar desde cero.
- **Al decidir:** guardá la decisión, el porqué y las alternativas descartadas.
- **Al resolver un bug:** guardá el síntoma, la causa y el arreglo.
- **Al cerrar la sesión:** guardá un resumen de lo hecho y lo pendiente.

## Reglas

- Nunca guardes secretos, credenciales ni datos personales: la memoria se puede exportar.
- Usá una clave de tema estable para actualizar en lugar de duplicar.
- Hasta F3, si el comando de memoria no existe, decilo y seguí sin memoria.
